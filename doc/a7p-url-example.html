ArcherBC2 — a7p:// URL example

This page demonstrates how to embed a shareable profile link that opens directly in ArcherBC2. The profile data is base64-encoded inside the URL — no server required.

Example link

Open profile in ArcherBC2

Generate a link from a .a7p file

Pick any .a7p profile file — a shareable link is generated locally in the browser (the file never leaves your machine).

URL format

a7p://open?payload=<URL-safe base64, no padding>

The payload is the raw binary content of a .a7p file encoded as URL-safe base64 (RFC 4648 §5: +→-, /→_, padding stripped). Standard base64 with %2B/%2F/%3D percent-encoding is also accepted.

Browser notes

  • Firefox / Safari: click the link above — a dialog will ask to open ArcherBC2.
  • Chrome: typing a7p:// in the address bar opens a search. Always navigate via a clickable link on a page.
